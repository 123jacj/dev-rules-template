# 统一编号规范

> 所有新项目统一采用本编号体系。编号**全局连续、不按模块分段**，保证可追溯、可交叉引用。
> 日期统一 ISO 8601（`YYYY-MM-DD`）。

---

## 一、文档编号（docs/NN-名称.md）

| 编号段 | 用途 | 是否必须 |
|---|---|---|
| 00 | 项目概览 | 必须 |
| 01 | 需求规格 / 需求分析 | 必须 |
| 02 | 范围与边界 | 必须 |
| 03 | 业务规则与状态机 | 按需 |
| 04 | 工程结构与规范 | 必须 |
| 05 | 技术验证清单 | 按需 |
| 06 | 阶段评审记录 | 必须 |
| 07 | 开发工作流 | 按需 |
| 08 | 自主迭代 / 长期协议 | 按需 |
| 09 | 任务池 | 必须 |
| 90 | 进度追踪 | 必须 |
| 91 | 风险登记册 | 必须 |
| 92 | 变更记录 | 必须 |
| 93 | 开发日志 | 必须 |
| 99+ | 报告（覆盖率 / 性能 / 烟测 / 发布等） | 按需 |

**规则**：
- 00-06 为产品文档，09 为任务，90-93 为过程管理文档，99+ 为报告。
- 中间留号给后续详细设计与接口文档；新文档只插入空号段或向后追加，**不重排已有编号**。
- `docs/active/` 放活跃文档；冻结设计移入 `docs/archive/`，并在原位留指针。

## 三、状态集（固定取值，不新增）

```
未开始 / 进行中 / 待自测 / 待联调 / 待验收 / 已完成 / 阻塞 / 已取消
```

**状态转换**：
```
未开始 ─开始─> 进行中 ─完成─> 已完成
                ├──> 阻塞 ─解除─> 进行中
                └──> 已取消（原因留痕到变更记录）
```
- `进行中 → 阻塞`：阻塞原因必填，引用 `RISK-NN`
- 任何状态变更必须在**当日开发日志**留痕

## 四、变更分级（rigor）

| 级别 | 触发条件 | 必走流程 |
|---|---|---|
| **轻量** | 补测试、修类型错误、调索引、加迁移 | TDD + 验证 |
| **标准** | 改公开接口 / 错误码 / 存储格式 / 外部行为 / 跨 2 个文件 | 轻量 + Context Declaration + Semantic Diff Review |
| **全量** | 架构变更、跨模块集成、公开契约变更 | 标准 + 子会话协议 + 建议新开会话 |

判断 4 问（任一为"是"即至少标准变更）：
1. 是否改变公开契约、接口签名、错误码或外部行为？
2. 是否改变持久化格式、迁移或存储语义？
3. 是否改变跨模块语义？（是 → 全量）
4. 修改范围是否超过 2 个文件？

不确定时**默认按标准变更处理**（保守策略）。

## 五、完成度口径

| 口径 | 公式 | 用途 |
|---|---|---|
| A · 任务数加权 | 已完成任务数 / 总任务数 × 100% | 默认看板、里程碑 |
| B · 工时加权 | Σ已完成实际工时 / Σ全部实际工时 × 100% | 滞后判定、对外汇报、复盘 |

> 滞后判定必须用口径 B（口径 A 会低估真实滞后）。
> 初始化脚手架产物（CLAUDE.md / 配置 / 目录骨架）**不计入**业务任务数。

---

## 六、滞后预警（满足任一即触发）

| 触发条件 | 阈值 |
|---|---|
| 工时完成度 < 时间进度 | 差值 ≥ 15 个百分点 |
| 连续两周无任务完成 | 连续 2 个周末检查无新增 |
| 里程碑实际达成晚于目标 | > 3 天 |
| 阻塞任务数 | ≥ 3 条 |
| 关键路径任务阻塞 | 立即触发 |

触发后按「砍非核心功能 → 简化前端 → 降级配置 → 降测试覆盖 → 简化错误处理 → 缩范围」顺序处理，且不砍核心链路、领域模型正确性、关键状态机测试覆盖与硬约束。每次触发须在开发日志记录触发条件与处理结果。

---

## 七、进度记录分页规则

- 明细**倒序追加**：新行插在表头分隔行下一行；**日期列必填**。
- 同一功能项状态变化**不改历史行**，一律追加新行；当前状态 = 所有分页中日期最新的一行。
- 单页阈值 **300 行**；换页三件事：新页标 `活跃` / 旧页标 `已冻结` 并指向新页 / 更新页索引。

## 八、时间预估与会话隔离

| 预计耗时 | 建议 |
|---|---|
| ≤ 30 分钟 | 当前会话继续 |
| 30-45 分钟 | 当前会话继续，完成后汇报 |
| 45-120 分钟 | 建议新开会话隔离 |
| > 120 分钟 | 必须新开会话，拆分子任务 |
