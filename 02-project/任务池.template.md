## 一、任务卡格式

每张任务卡按以下字段填写，缺字段不得标记为「已完成」（见 `agents.md` 过程合规硬检查）。

```text
T-NNN · 任务标题
- 阶段 / 模块：
- 描述：
- 关联需求：FR-NNN / —
- 预估工时(h)：
- 依赖任务：T-NNN / —
- 验收标准：
- TDD：先写失败的测试 → 最小实现 → 重构
- 验证命令：
- 验证证据：（路径或输出摘要）
- 变更级别：轻量 / 标准 / 全量
- 状态：未开始 / 进行中 / 待自测 / 待联调 / 待验收 / 已完成 / 阻塞
- 阻塞原因：RISK-NN（仅状态=阻塞时填）
```

## 二、变更级别与必填字段

| 级别 | 必填字段 |
|---|---|
| 轻量 | `TDD` + `验证命令` + `验证证据` |
| 标准 | 轻量 + `Context Declaration` + `Semantic Diff Review` |
| 全量 | 标准 + 全部字段 |

## 四、状态转换

```
未开始 ─开始─> 进行中 ─完成─> 已完成
                ├──> 阻塞 ─解除─> 进行中
                └──> 已取消（原因登记到 92-变更记录）
```

## 五、维护规则

- 任务状态变更必须同步当日 `93-开发日志`
- 新增任务在清单追加行，不改动历史行
- 任务取消不删除，标「已取消」并在变更记录留痕
